# Color Picker in C++ (ESP8266 & LittleFS)

Проєкт для керування RGB-світлодіодом за допомогою мікроконтролера **ESP8266 (Wemos D1 mini)** через веб-інтерфейс, який завантажується з вбудованої файлової системи **LittleFS**.

---

## 🛠 Технології та Бібліотеки

* **Платформа:** ESP8266 (Arduino / PlatformIO)
* **Вебсервер:** `ESP8266WebServer`
* **Файлова система:** `LittleFS` для зберігання HTML/CSS/JS файлів фронтенду.
* **Апаратна частина:** RGB-світлодіод із шимізацією (PWM) на виходах.

---

## 📌 Підключення (Wiring)

| Пін ESP8266 (Wemos D1) | Колір світлодіода | Опис |
| :--- | :--- | :--- |
| **D5** | Червоний (Red) | PWM-керування червоним каналом |
| **D6** | Синій (Blue) | PWM-керування синім каналом |
| **D7** | Зелений (Green) | PWM-керування зеленим каналом |

---

## 🚀 Налаштування та Запуск

1. Склонуйте репозиторій або відкрийте проєкт у середовищі **PlatformIO**.
2. Переконайтеся, що у папці проєкту створено директорію `data` із файлом `index.html`.
3. Завантажте файлову систему на плату (`PlatformIO: Build Filesystem Image` та `Upload Filesystem Image`).
4. Завантажте прошивку у мікроконтролер (`Upload`).
5. Підключіться до створеної платою Wi-Fi мережі (або налаштуйте підключення до домашнього роутера у коді) та відкрийте IP-адресу плати у браузері.
